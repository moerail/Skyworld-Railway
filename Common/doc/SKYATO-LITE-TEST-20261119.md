# SkyATO-Lite 0.1.0 测试记录 — 2026-11-19

配套：STA 2.3.0、STF 4.1.0、STCS 4.2.0、SkyPCC 2.2.0、SkyATO-Lite 0.1.0。
状态：隔离测试候选，未部署生产服。

## 离线验证

- 使用本地 Shiroha 26.2 和 26.3 依赖分别编译、运行 Java 回归；每版 96 个测试入口。
- SAL 字段：station 第三行秒数/第四行运营线路；property/V_target 单位；message 文本与秒数；非法输入拒绝。
- 有向闭环、断环、分支歧义、沿线进度、站点相邻边切换、停车目标后的 MA 余量。
- 自动列车 FS 的身份、图版本、路径、过期及迟到请求 fencing；停稳前拒绝 release，观测更新后可重试。
- 自动 SR 必须先进入待批，管理员批准后才能获得可执行 SR；释放后下一段重新待批。
- TIMS 未知撤销授权；自愈策略不确认真实缺车/编组变化/间距故障，不清除独立 ATP Trip 或保持期间的 EoA 超越。
- 原有 MA、道岔、占用、TIMS、实体/显示、协议双版本、STA 可选加载、PCC 网关等回归。
- PCC JavaScript 线路显示测试、328 条四语言键及占位符检查通过；app.js 语法检查通过。

## 26.3 实车隔离测试

测试使用新建本机世界、人工构造的合法 RailGraph 与实际矿车实体。测试夹具负责铺设矩形环线、登记测试编组及测试线路；
业务插件仍按 STA 控制契约运行，测试夹具没有接管列车驾驶。没有玩家登录或乘坐。

流程：车辆段 maintown → 首站停靠 → 一圈 → 最后一站停靠 → 选择空闲停车位 → 回库 → 释放 MA → SB / IDLE。

通过记录：

```text
WATCH 71 8.588471563077634,0.5 0.0 FS 到达 CONFIRMED distance=254.36156854416745
WATCH 72 8.588471563077634,0.5 0.0 SB IDLE CONFIRMED distance=254.36156854416745
RESULT true Empty train completed loop and depot return; distance=254.36156854416745
```

停车标横坐标 8.5，最终偏差约 0.09 格。测试服由夹具自行正常关闭。
原始证据在 `Common/target/sal-live-472770d2/live-run.log` 与该目录 `plugins/sal-live-result.txt`。

实车过程中发现并修正：轨道块中心查询提前切边导致的误判偏离；把停车标直接作为 EoA 导致保护曲线阻止对位；
车端停稳先于 STCS 上报更新，第一次 release 被拒绝而无法回到空闲状态。
通过实车测试后，继续补充了 SR 恢复分支的限次等待和 TIMS 故障原因区分，并纳入双版本回归。

## 验证边界

- 本次夹具预先加载了铺轨区块，因此证明的是“无乘客也能完成运行任务”；不单独证明强制卸载/重载后的全部恢复场景。
- 尚未进行实际站场的多车竞争、长编组清岔、折返、强制区块卸载、生产存档迁移和重启故障注入验收。
- Title 的真实玩家画面、上下车及多人覆盖需人工验收。
- PCC 浏览器回归脚本因本机缺少 Playwright 依赖未执行；PCC 网关和 JavaScript 静态/字典测试已执行。
- 当前默认 FS 要求有效的驾驶声明/自动任务和 STCS 授权；不恢复旧伪 ATO 无 MA 行车。

建议先使用一条隔离线路、一列车验证牌子与线路配置，再逐步加入道岔、多车与乘客。
