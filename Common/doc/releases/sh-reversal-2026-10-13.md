# SH 停稳换向修复 — STF 4.0.9 / STCS 4.1.1

SH 调车中，司机停稳后经中立切换行驶方向，不再需要重新执行 `/stcs ma sh`。STCS 保留同一驾驶租约下的 SH 申请，按照新行驶端的位置、方向和当前占用／道岔条件重新计算 MA。旧方向的 MA 不授权反向行驶；新方向授权到达并通过车载校验前继续保持制动。

车载校验允许 SH 在物理行驶方向未变时经过中立档，仍检查实际方向、遥测来源、新鲜度、驾驶租约、会话和拓扑版本。新授权由换向后的遥测支持。旧前方预约保留到新授权被车载确认接收，车身占用不清除。限速、EoA 制动、道岔和占用冲突检查保持有效；新方向无可用路径时不能牵引。

FS、SR 换向仍需重新申请。SH 运行中换向、TIMS 失效、驾驶租约或保护通道变更、拓扑重建仍会使申请失效；本修复不会自动恢复这些被撤销的申请，也未增加 TIMS 管理员 override。

## 安装与验收

配套替换 STF 4.0.9 与 STCS 4.1.1，停稳列车并正常关闭服务器后安装。保留现有插件数据、配置和账本。STA、PCC 协议不变。本地 Java 验证与生产服实机验收分开记录。

实机检查：完整编组停稳后取得 SH，前进停车，经中立换向后再次运行，不重新申请；反复换向；检查新方向占用或道岔不就绪时保持停车；核对 FS、SR 换向仍要求重新申请。测试中不得删除占用证据。
