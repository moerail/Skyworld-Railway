# SkyRail Suite 4.0.10 — 为了同志 / Ради товарищей

**2026-10-26 · SkyTrainFolia 4.0.10 / STCS 4.1.1 / SkyworldTrainAPI 2.2.0 / SkyPCC 2.1.0**

## 中文

本次「为了同志」更新为 STF 加入与中文、英语、法语、日语并列的俄语界面，并提供俄语总手册、玩家司机手册和自动告示牌指南。

- 在游戏内使用 `/st lang ru` 切换俄语；语言偏好会保存，重启后恢复。也接受 `ru_RU`、`ru-RU`、`russian`。使用 `/st help ru` 临时查看俄语帮助。
- 俄语覆盖驾驶台、侧栏、MA/ATP BossBar、保护模式、TIMS/MA 回复、停车标记和库莉酱司机引导，并补充旧版命令、基础设施查询、告示牌反馈及输入错误的俄语呈现。
- 已有自定义 `driver-guide.yml` 不会被覆盖；缺少的俄语条目使用 JAR 内默认值。可按现有语言相同方式添加 `ru` 文案。
- 原始诊断、命令、协议标识和玩家自定义名称保持原意；语言切换不改变驾驶权、制动或 MA 分配规则。网页 PCC 的语言设置独立，本次没有新增俄语网页界面。
- 同时包含当前源码中的可点击 TIMS 确认与司机交接处理：先恢复编组完整性、全列停稳，再按提示 `/st tims ack`；只有需要时继续处理 TR 和旧 MA，确认不会绕过检查或自动缓解制动。

俄语文档：[总手册](../../README.ru.md) · [司机手册](../driver/README.ru.md) · [自动告示牌](../BASIC-AUTOMATIC-SIGNS.ru.md)

### 安装与验证

发行附件包含四个配套 JAR、源码 ZIP 和 `SHA256.json`。STF 单个 JAR 同时包含 Shiroha 26.2 和 26.3 显示适配器，需要 Java 25。单独安装 STF 的服务器可只更新 STF；使用完整套件的服务器应按上述兼容版本核对已安装组件。

停服、备份后替换对应 JAR，移除同一插件的旧 JAR，再启动。保留列车、RailGraph、占用账本、证书、令牌和自定义词库；不要通过删除数据完成升级。

**在 Shiroha 26.2 与 26.3 上分别通过 88 项 Java 测试。** 包含俄语文案完整性、格式占位符、语言偏好保存/恢复、旧词库缺项回退及俄语自定义覆盖。实服界面验收仍待完成；构建过程没有修改服务器安装目录。这是实验性 Minecraft 铁路插件，不是认证铁路安全系统。

## Русский

Обновление **«Ради товарищей»** добавляет русский интерфейс STF наравне с китайским, английским, французским и японским, а также русские версии общего руководства, руководства машиниста и руководства по автоматическим табличкам.

- Выполните `/st lang ru` в игре. Выбор сохраняется и восстанавливается после перезапуска. Также принимаются `ru_RU`, `ru-RU`, `russian`. `/st help ru` временно показывает русскую справку.
- Переведены кабина, боковая панель, BossBar MA/ATP, режимы защиты, ответы TIMS/MA, маркеры остановки и подсказки Кури-тян. Дополнены русские ответы старых команд, запросы инфраструктуры, сообщения табличек и ошибки ввода.
- Существующий пользовательский `driver-guide.yml` не перезаписывается. Для отсутствующих русских записей используются встроенные значения JAR. Собственные тексты добавляются в разделы `ru` так же, как для других языков.
- Исходные диагностические сообщения, команды, идентификаторы протокола и пользовательские имена сохраняются. Смена языка не меняет управление, торможение или правила выдачи MA. Язык веб-PCC выбирается отдельно; русский веб-интерфейс этим выпуском не добавляется.
- Включены текущие изменения подтверждения TIMS и передачи управления: сначала восстановите целостность состава и полностью остановите поезд, затем используйте кликабельную `/st tims ack`. После этого обрабатывайте TR и прежнюю MA только при необходимости. Подтверждение не обходит проверки и не отпускает тормоза автоматически.

Документация: [Общее руководство](../../README.ru.md) · [Руководство машиниста](../driver/README.ru.md) · [Автоматические таблички](../BASIC-AUTOMATIC-SIGNS.ru.md)

### Установка и проверка

Вложения выпуска: четыре совместимых JAR, ZIP исходников и `SHA256.json`. Один JAR STF содержит адаптеры отображения для Shiroha 26.2 и 26.3; требуется Java 25. Сервер с отдельным STF может обновить только STF. Для полного комплекта проверьте совместимость установленных компонентов с версиями в начале заметки.

Остановите сервер, создайте резервную копию, замените нужные JAR, удалите старый JAR того же плагина и запустите сервер. Сохраните поезда, RailGraph, реестр занятости, сертификаты, токены и пользовательский словарь. Для обновления не нужно удалять данные.

**На Shiroha 26.2 и 26.3 пройдено по 88 Java-тестов.** Проверены полнота русских текстов, форматные аргументы, сохранение/восстановление языка, встроенные значения для старого словаря и пользовательские русские фразы. Проверка интерфейса на работающем сервере ещё ожидается; сборка не изменяла установленные серверы. Это экспериментальный железнодорожный плагин Minecraft, не сертифицированная система безопасности железных дорог.
