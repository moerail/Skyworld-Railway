# STA 2.1.2：桌面字号、线路列表、标签避让和运行事件

本次更新包含 STA 服务端 2.1.2 和桌面调度台 2.1.2。STF、STCS、SkyPCC 的业务逻辑未修改。

- 顶部“字号”支持 8–24，影响地图标签和界面字体。手工输入后按 Enter 或移开焦点生效。
- 右侧“线路”页列出当前世界的已确认线路。所有线路默认中性色；选择线路后可设置临时颜色或恢复无着色。颜色仅保留在当前程序会话，重新启动即清除，不写入服务器。占用、未知和预约图层继续覆盖在线路之上。
- 地图标签按选中列车、其他列车、道岔、普通节点的顺序放置，根据实际文字尺寸避让标签和图标，用引线关联目标。空间不足时隐藏放不下的标签并显示数量；放大或平移后重新计算。
- 右侧“运行事件”页读取与网页 PCC 相同的 `RailwayEventService`，显示服务端事件时间、类型、对象、原因、操作人和详情，支持警告筛选。时间按客户端本地时区显示并带时区偏移。服务端日志最多保留 500 条，客户端按会话及序号去重，服务端重启会建立新事件会话。
- 原“调度”页状态消息补充本地时间戳。运行事件连接状态独立显示，断线或源不可用时不把旧事件标成实时数据。

## 更新方法

1. 停服，将旧 STA JAR 替换为 `SkyworldTrainAPI-2.1.2.jar`，不要同时保留两个 STA 版本。
2. 保留 `plugins/SkyworldTrainAPI` 的配置、证书和密码文件，使用原 `start-sta-remote.cmd` 启动。无需重跑 setup 或重新生成令牌。
3. 客户端换成 `SkyRail-Dispatcher-2.1.2.pyz`（需要 Python 和 Tkinter），把原连接 JSON 放在旁边，输入原令牌连接。

新客户端可连接旧 STA，但旧服务端没有 `events.list` 接口，会明确提示更新 STA JAR；地图与原调度操作仍使用原接口。

## 验证

桌面测试覆盖默认中性色、临时颜色设置／重置、占用色保留、字号边界和错误输入、标签边界框不重叠、事件去重、警告筛选、会话切换及状态时间戳。实际服务器上的地图密度、网络连接及运行事件仍需部署后验收。
